# Aura Vibe Retail Hub

​"Build a fully functional, production-ready, ultra-modern e-commerce retail mobile web application for Aura Vibe, precisely inspired by Temu’s high-conversion user interface shown in the provided screenshots and video recordings.
​1. Centralized Backend Integration (Supabase):
​Use Supabase as the primary backend database for products, categories, dynamic pricing, and stock.
​Important Account Mapping: All database tables, storage buckets, and API configurations must be strictly linked and synchronized under the core administrative account and email: auravibepro@gmail.com. No Google Sheets. Ensure lightning-fast and scalable retail loading.
​2. Temu-Inspired UI & Design (Zero App Logo Inside):
​The entire app interface must be clean, minimalist, and modern. Do NOT place any Aura Vibe brand logo inside the app header or content pages. Only focus on high-converting product layouts.
​Top Header & Search: Clean search bar with instant category filtering.
​Scrolling Ticker: A dynamic, animated announcement ticker at the top for real-time marketing deals and flash offers.
​Categories: Interactive circular category grid with 'HOT' badges (Cosmetics, Hair Removal Spray, Nail Polish Thinner, Face Masks, Personal Care).
​3. Product Detail View & Video Preview:
​When a user clicks on any product, open a detailed product view.
​Include a smooth product image gallery alongside a compact product video demo preview player (supporting short looping video demonstrations of the item in action).
​Color/Variant Selectors: Clean, interactive variation boxes (e.g., White, Green, etc.) with badges.
​Quantity Controls: Intuitive quantity adjusters (+ and - buttons) allowing smooth quantity changes.
​Quick Add-to-Cart Modal: A sleek overlay confirming 'Added to cart' with an option to go straight to the cart or continue shopping.
​4. Shopping Cart & Frictionless WhatsApp Checkout:
​Fully working cart page where users can select items, adjust quantities, view total prices in PKR, and see active deals or free shipping progress bars.
​Zero Complications Checkout: A short, frictionless checkout form asking only for essential buyer details: Customer Name, Phone Number, and Delivery Address/Location (no lengthy or unnecessary fields).
​Direct WhatsApp Integration: Clicking 'Place Order' instantly formats all cart items, variants, quantities, and customer details into a neat message and redirects/sends it directly to the store owner's WhatsApp number.
​5. Complete Graphic Admin Panel (Full Control):
​A secure, password-protected Admin Dashboard accessible via an intuitive button.
​Visual CRUD Controls: Graphic interface allowing the admin to easily Add, Edit, or Delete products, change product names, update PKR prices, upload/change product images and demo videos, and manage categories visually without touching any code.
​UI Accessibility: Ensure clean, prominent buttons are present everywhere necessary for smooth navigation and management."
